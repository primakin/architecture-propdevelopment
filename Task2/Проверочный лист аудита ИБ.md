# Проблемы и приоритеты компании
- Нет координации между точками регистрации нового клиента, на уровне систем обработки данных нет ограничений на доступ к данным - в проверочный лист надо включить раздел "управление доступом".
- API управляющих компаний используются без единых политик безопасности и без системного контроля за передаваемыми данными - в проверочный лист надо включить раздел "безопасность данных".
- Одна из потребностей бизнеса - отреагировать на инциденты и рыночные изменения. Включаем в проверочный лист раздел "управление инцидентами".
