# Требования к безопасности
- В базе данных PropDevelopment хранятся только биометрические шаблоны, полученные из фотографий собственников (BLOB, ассоциированный с id собственника). Во внешние сервисы также передаются только шаблоны.
- Преобразование фотографий в шаблоны реализуется через проприетарное приложение, развернутое в инфраструктуре PropDevelopment. Приложение поставляет партнер, реализующий сервис интеллектуального домофона.

# Протоколы аутентификации и авторизации
- Для входа в приложение и консоль управления "Умным домом" используется MFA (отправляем OTP на устройства собственников/администраторов).
- Для разграничения прав администраторов используем RBAC (например, "право на подключение пользователя к сервисам" для роли Администратора, "право смотреть логи устройств" для Аудитора).
- Соединение с сервисом партнера реализуется через mTLS.

# Взаимодействие между системами предприятия и внешней платформой
- PropDevelopment загружает на внешнюю платформу только биометрические шаблоны собственников (для домофонов), номера автомобилей (для шлагбаумов) и соответствующие права доступа (вход разрешен/запрещен). ФИО, номера телефонов и другие персональные данные **не** отправляем. 
- Внешняя платформа нотифицирует сервисы PropDevelopment о факте доступа конкретного собственника в помещения с помощью хэшей биометрических шаблонов (или номера автомобиля). Связь хэша с пользователем осуществляется на уровне сервисов PropDevelopment. Информация о доступе логируется.
- Вычисление шаблонов реализуется с помощью проприетарного приложения, развернутого в инфраструктуре PropDevelopment. Приложение поставляется партнером, предоставляющим сервис умного домофона.
	- Плюсы: 
		- персональные данные не покидают периметр PropDevelopment;
		- домофоны и шлагбаумы будут работать даже при проблемах со связью.
	- Минусы: 
		- возможна задержка при обновлении прав на конечном оборудовании;
		- повышенные требования к самому оборудованию (домофон должен уметь работать с биометрическими шаблонами, количество самих шаблонов ограничено объемом памяи домофона);
		- зависимость от проприетарного приложения для расчета биометрических шаблонов.
